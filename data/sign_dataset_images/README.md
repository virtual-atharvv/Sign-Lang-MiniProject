# Decoded Dataset Sign Skeleton Images

This directory contains decoded visual keyframe skeleton PNG images rendered directly from the official **INCLUDE ISL Benchmark Dataset**.

Each image presents a 4-keyframe composite showing:
- **Upper Body / Pose**: Cyan keypoints (`#38bdf8`) & blue skeletal joints
- **Left Hand**: Emerald green keypoints (`#34d399`) & finger joints
- **Right Hand**: Vibrant pink keypoints (`#f472b6`) & finger joints
